# SahiTol Recycler & Admin Web Application

Web application built with React, Vite, TypeScript, and TailwindCSS for formal recyclers, administrators, public verification, and illustrative economics.

## Tech Stack
- **Framework**: React 18, Vite 5, TypeScript
- **Styling**: TailwindCSS
- **State & Data**: React Router 6, TanStack Query 5
- **Forms & Validation**: React Hook Form, Zod
- **Visualizations & Maps**: Recharts, MapLibre GL
- **Icons**: Lucide React
- **Testing**: Vitest, React Testing Library

## UI Gate
In compliance with `docs/05_DESIGN_STITCH.md`, all visual screens and state variants are generated by the project owner in Google Stitch. The web routing, state containers, and API interfaces are staged to receive and render approved Stitch components upon notification.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run type check
npm run typecheck

# Run test suite
npm run test
```
