# Explicit future scope — retained, not silently omitted

Every item below has a requirement, task and acceptance case in the canonical [catalog](planning/catalog.json), [requirements](15_REQUIREMENTS.md) and [tracker](08_TRACKER.md). These are not part of the Sep30 software-release denominator. They require explicit owner promotion, concrete design/data prerequisites and new dependency/acceptance planning. Merely mentioning a roadmap feature does not authorize implementation. All six selected must-haves remain RELEASE.

| Task | Future capability | Key boundary |
|---|---|---|
| F001 | Assisted field-agent/SHG/aggregator accounts | Delegation and collector consent; no silent impersonation |
| F002 | Multi-collector batching/inventory/pickup operations | Per-collector provenance and proceeds reconcile |
| F003 | Predictive prices and automated price feeds | Adequate licensed temporal data; baseline and uncertainty |
| F004 | Active learning and wider classifier | Consented image policy first; current model uses public images only |
| F005 | Learned ranking/advanced anomaly detection | Hard route filters retained; human review, no fraud accusations |
| F006 | Voice input/advanced multilingual assistance | ASR validation/confirmation; bundled output audio is already required now |
| F007 | Route optimization | Capacity/consent/map rights; no default continuous GPS |
| F008 | ERP/GST/PRO/brand/CPCB adapters | Actual contracts and credentials; procurement export now is not integration |
| F009 | Downstream processing/mass balance | Evidence before claiming recycled or recovered output |
| F010 | Server Ed25519 signatures | Key lifecycle and trust distribution, not blockchain |
| F011 | Relative recovery indicator and carbon/LCA estimate | Exact supporting research, uncertainty and owner promotion; no fake JNARDDC formula |
| F012 | Consented regional pilot/real partnerships | Actual participants and evidence; does not erase current fieldwork gap |
| F013 | More cities/languages/waste streams | Region/route/source/safety review; avoid generic all-waste scope drift |
| F014 | Government/sector aggregation dashboards | Representative data and privacy; no national extrapolation from demo |
| F015 | Advanced dispute adjudication/support | Basic dispute/changed-term records required now; formal case management later |
| F016 | Optional payment execution/messaging/downstream monetization | Separate lawful provider/fee/settlement design, no required paid API now |
| F017 | Shareable collector identity and partner services | Consent/minimal PII; no promised credit/welfare eligibility |
| F018 | Production operations/scale | Add queues/cache/infrastructure only for measured needs |

Detailed completion criteria and physical source lines are in each F task and R-FUT/FT case. Promotion changes scope, dependencies, screen inventory, APIs/data/security, tests and roadmap in one audited change; don't simply change a DEFERRED status to DONE.

Explicitly rejected as current requirements: blockchain/custom LLM, perfect 14-category classifier, nationwide real-time prices/routing, continuous tracking, compulsory digital payment/SMS/email/WhatsApp, universal CPCB integration, fabricated official certificates or exact mineral value. Some underlying capabilities may be reconsidered under the bounded future items above; false claims and invented research are never acceptable features.
